# okrafood

One-page e-commerce for premium escargots delivery in Abidjan, Côte d'Ivoire.

## Stack
- HTML5 + Tailwind CSS (CDN)
- Alpine.js for interactivity
- GSAP for animations
- Dockerized Nginx for deployment

## Deployment
Auto-deployed via Coolify on push to `main`.
Live: https://okrafood.com
